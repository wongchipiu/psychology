# 亲子共看与生活练习手册

[[00-项目导航|返回项目导航]]

## 这套动画怎样才不会变成说教

故事的任务不是让孩子背下心理学家的名字，而是让孩子在角色面临麻烦时看见一种新的可能：

> 感觉可以很强，想法可以很响；角色仍能观察、选择、行动、求助和修复。

真正的心理教育发生在三个地方：

1. 角色没有立刻做到；
2. 旧办法产生了可信的代价；
3. 新办法靠情节验证，而不是靠导师宣布正确。

## 家长不是讲师，而是共同练习者

观看前不说“这集就是讲你上次发脾气”。孩子一旦感觉作品是为纠正自己准备的，注意力会转向防御。

更好的使用方式：

- 成人先在自己身上使用相同语言；
- 把角色当第三方，允许不同解读；
- 孩子只需要喜欢、讨厌、质疑或改编故事，不需要交心得；
- 方法在平静时游戏化练习，在冲突时只做简短提示；
- 冲突后成人也复盘并承担自己的部分。

## 一集的完整共看流程

### 播放前：不预告教育目的

只说：“今天看一集新故事。你帮我看看哪段最好／最假。”

如果孩子不想看，不把拒绝解释为抗拒成长。可以换时间、让他只听故事、看分镜或参与配音。

### 播放中：不暂停提问

除非孩子主动停，不在关键情节中插入“你看懂了吗”。让情绪和悬念完整发生。

### 播放后：一问、一听、一停

1. 只问一个开放问题；
2. 听答案，不纠正标准；
3. 对话仍有兴趣再继续，没兴趣就结束。

可选问题：

- “哪一个角色最像真的？”
- “哪个决定你不同意？”
- “如果删掉一句台词，你删哪句？”
- “如果重写结局，你让谁做什么？”
- “这个办法在哪种情况会没用？”

最后一个问题尤其适合15岁观众，能防止方法被神化。

### 24小时后：成人先示范

自然场景中成人可以说：

> “我脑子里正在刷一条‘赶快解决’的回声。我先看事实，十分钟后再谈。”

或：

> “我现在有点急急怪。我的下一步是先把水擦掉，再处理打碎的杯子。”

不要紧接着说“你也应该这样”。

## 15岁与8岁不能使用同一种带领方式

| 维度 | 15岁女孩 | 8岁男孩 |
|---|---|---|
| 核心需要 | 自主、尊严、复杂性、隐私 | 安全、动作、重复、清楚边界 |
| 最佳入口 | 角色动机、世界观漏洞、编剧选择 | 怪兽、道具、身体动作、游戏 |
| 提问方式 | “你不同意哪里？”“还有别的解释吗？” | “你想演谁？”“下一步多小？” |
| 避免 | 追问私人情绪、套诊断、把故事对应她 | 长篇抽象解释、要求静坐、善恶标签 |
| 练习形式 | 可私下记录、改写台词、选择参与程度 | 画卡、玩偶演练、颜色灯、击掌口令 |
| 成人角色 | 尊重她拥有自己的解释和方法 | 提供结构、安全与共同示范 |

## 12周家庭实验说明

### 第1周：暂停手势

全家各自设计手势。手势只表示“暂停自动反应”，不能表示“闭嘴”。被提示的人可选择现在停、换地点或约返回时间。

### 第2周：能量灯

每人画自己的绿／黄／红状态和希望获得的帮助。别人不能擅自宣布“你现在红灯”。

### 第3周：教练台词

把“怎么又这样”改成“发生了什么、影响是什么、下一步是什么”。成人贡献的旧批评句应不少于孩子。

### 第4周：事实侦探

用图片、短片或虚构案件区分事实与猜测。不要用家庭争执强迫孩子承认成人版本才是事实。

### 第5周：价值动作

每人选择自己的价值。孩子可以选创造、朋友、好奇、游戏、公平，而不是只能选努力学习。

### 第6周：三颗星

检查任务的自主、胜任、联结。成人负责调整一个家庭环境因素，不能把全部改进责任给孩子。

### 第7周：五分钟启动

全家同时做自己的小任务，时间到可以停。成人如果继续，也不要求孩子跟着加时。

### 第8周：无打扰岛

设置10—25分钟共同专注；内容可学习、创作、阅读、拼装或玩耍。专注不等于只有功课有价值。

### 第9周：盾牌与桥

每人写一条边界和一条仍愿意保持的联结。例：“我不接受辱骂；我愿意在都不用辱骂时继续谈。”

### 第10周：修复拼图

每人分享一个曾修复的小事；可以只画不说。修复者不能要求受影响者马上原谅。

### 第11周：多面拼贴

“别人常见的我／很少看见的我／正在学习的我／想贡献的我”。每人有权保密一格。

### 第12周：家庭卓越宪法

只保留5条能实际执行的原则，贴在共同空间。90天后可修改，不能把它变成永远不许质疑的家规。

## 冲突中怎样提示而不激怒孩子

提示越长，越像控制。优先从环境和自己开始：

- “我先把声音放低。”
- “我们一次只谈一件事。”
- “你想要空间，还是我陪你停两分钟？”
- “这个规则还在，但现在不是讲清它的好时机。”
- “我会在8点回来，不消失。”

少说：

- “你又被回声控制了。”
- “快用光之四步。”
- “先正念一下再跟我说。”
- “你的想法不是事实，所以不要生气。”

心理工具不能成为否定孩子经验的高级词汇。

## 从动画到生活：迁移四步

### 1. 角色语言

“岚遇到了必须一次画对的回声。”

### 2. 成人自我示范

“我写报告时也出现了类似回声，结果一直没打开文件。”

### 3. 共同改造工具

“她用一厘米刻线。我的版本是先写标题。你会把它改成什么？”

### 4. 真实低风险试验

在不太困难的任务中试5分钟，记录结果。不要等到重大考试、强烈冲突或孩子崩溃时第一次练。

## 给编剧和动画团队的心理内容检查表

每集创作会前回答：

- 本集角色真正想要什么，不只是“学会道理”？
- 旧策略为何合理，它过去保护过什么？
- 旧策略在本集产生什么可见代价？
- 新策略由哪个线索被发现？
- 新策略是否需要练习、协作或付出，而非魔法治愈？
- 角色是否保留选择、个性和不完美？
- 有没有把心理问题归咎于意志或家长？
- 是否展示了环境、关系或任务设计的调整？
- 结尾有没有留一点未解决空间？
- 删除所有心理术语后，故事是否仍然成立？

最后一项若为“否”，说明剧情还只是包装过的讲课。

## 每集故事引擎模板

1. **愿望：** 角色想得到一个具体结果。
2. **触发：** 正常压力唤起一种旧策略。
3. **升级：** 旧策略短期有效，随后放大代价。
4. **误解：** 角色以为必须消灭感觉／证明自己／独自完成。
5. **线索：** 画面或队友提供反常证据。
6. **选择：** 角色在不确定中做一个小而有代价的不同动作。
7. **反馈：** 关卡规则改变，验证的是过程而非人格。
8. **余波：** 关系、物品或世界留下痕迹；不恢复成“从未发生”。
9. **钩子：** 新问题扩大本季主线。

## 不同心理能力的视觉化方法

| 心理能力 | 适合的画面 | 不推荐画面 |
|---|---|---|
| 注意觉察 | 运动突然静止、视野从隧道变宽、三个环境线索点亮 | 头顶出现“正念”两个字 |
| 情绪容纳 | 能量灯变色但不熄灭、波浪通过而非被炸掉 | 一次呼吸让所有问题消失 |
| 认知解离 | 字幕从实体墙变成飘过的字片 | 角色说“负面想法都是假的” |
| 价值选择 | 无奖励路线仍被选择、指南针指向行动而非奖品 | 神秘力量宣布唯一正确价值 |
| 微行动 | 一厘米刻线、小脚印、逐格亮起 | 靠意志突然完成巨型任务 |
| 联结边界 | 两人共同托住结构、盾牌与桥同时出现 | 一味退让被写成善良 |
| 修复 | 拼痕保留、道歉后仍需重建 | 说对不起后一切复原 |

## 公开发布与原创化路线

如果用于家庭观看或非公开样片，可先验证故事节奏。若准备公开传播或商业化，需处理现有IP授权。未取得授权时，建议做完全原创化转换，不能只改角色名字或颜色。

### 15岁版本原创化方向

| 同人功能 | 原创替换方向 |
|---|---|
| 凹凸大赛 | “星环试炼”：一座以选择数据训练预测机器的移动城 |
| 元力技能 | 每个少年通过“心像工具”改变局部物理规则 |
| 金小队功能 | 行动者、观察者、怀疑者、感知者四种互补角色，重写外形、背景、关系和语气 |
| 积分系统 | “可能值”：系统预测一个人值得被分配多少未来资源 |
| 回声迷宫 | 可保留为原创核心，但重做造型、规则史与反派动机 |

原创长篇名可暂定《星环之外：回声城》。岚可升级为主角，第一季核心保持“预测不等于命令”。

### 8岁版本原创化方向

| 同人功能 | 原创替换方向 |
|---|---|
| 奥特英雄 | “光能守护员阿湛”：可变大，但能量来自城市协作节点 |
| 能量灯 | “观察灯”：蓝／黄／红显示负荷，不代表人格好坏 |
| 怪兽单元剧 | “城市情绪工程队”处理被黑雾放大的日常麻烦 |
| 光线必杀 | 工程、合作、边界和创意装置；必要战斗只用于保护 |
| 光之国 | “晨星站”：训练守护者观察、修复与传递技能 |

原创长篇名可暂定《光能工程队：急急怪来了》。保留乐乐、米粒、急急怪与黑雾塔，重新设计英雄即可形成原创资产核心。

## 隐私与伦理

- 不把孩子的真实创伤、诊断、学校冲突直接改编后公开；即使改名，细节组合仍可能识别个人。
- 让孩子决定自己的作品、声音和形象是否用于公开视频。
- 不在宣传中声称动画可以治疗ADHD、创伤、焦虑或抑郁。
- 若与学校或机构合作，明确内容是心理教育，不是诊断或治疗。
- 评论区若面向未成年人，应设计审核、隐私和求助信息。

## 何时停止家庭讨论并寻求帮助

当故事触发孩子明显持续不适、创伤回忆、恐慌、强烈解离或自伤想法时，停止追问和练习，先提供安全陪伴并联系合格专业人员。孩子说“不想谈”本身应得到尊重；紧急安全风险除外。

## 带领者的最后提醒

最有力量的“动画课后练习”不是让孩子复述四步，而是孩子看见：成人也会着急、误解、失手；成人愿意停下来，不把羞耻传下去，能回来道歉、调整规则，并继续爱一个没有立刻改变的人。
