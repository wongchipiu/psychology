# 第18天｜羞耻与罪疚

> [!summary] 今日目标
> 将“我整个人有问题”转化为对具体行为、需要和修复可能的辨认。

## 0—10分钟｜安定

环顾现实环境，确认你此刻是安全的成年人。若回忆强度超过6/10，改用较轻事件。

## 10—25分钟｜核心观念

羞耻使人想隐藏整个自我，罪疚则更可能指向具体行为。两者都可能与阴影有关：羞耻把正常需要赶入阴影，自我攻击又可能掩盖真正需要承担的责任。

有时“我真差劲”比“我需要道歉并改变做法”更容易，因为前者虽然痛苦，却不要求具体行动。成熟整合既反对无边界自责，也反对用童年原因免除现在的责任。

## 25—50分钟｜练习：拆开两种声音

把纸分两栏：

| 羞耻的结论 | 可承担的具体责任 |
|---|---|
| 我不值得被爱 | 我在冲突中说了伤人的话，需要道歉并改变暂停方式 |
|  |  |

写至少5组。再为一项“其实是正常需要”的内容写一句允许语言。

## 50—60分钟｜整合

- 自我攻击正在要求我躲起来，还是推动修复？
- 哪个需要不必再被羞耻化？
- 哪项责任可以在本周落实？
