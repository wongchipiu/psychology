# 第14天｜黄金阴影

> [!summary] 今日目标
> 把羡慕和理想化转化为尚未发展的个人能力。

## 0—10分钟｜安定

想起一个你欣赏或羡慕的人。注意身体里是扩张、兴奋、酸涩还是自我贬低。

## 10—25分钟｜核心观念

阴影并不都是“黑暗面”。有些人在成长中学会缩小自己，于是自信、创造、领导力、享受和被看见的愿望也进入阴影。这些积极潜能常被投射到偶像、导师或伴侣身上，被称作“黄金阴影”。

收回正面投射不是否定对方优秀，而是不再把某种人类能力视为自己绝对不可能拥有。参见 [[投射]]。

## 25—50分钟｜练习：把羡慕翻译成能力

选择3个羡慕对象，完成：

| 对象 | 我羡慕的具体行为 | 背后的能力 | 我的最小版本 |
|---|---|---|---|
|  |  |  |  |

“最小版本”必须能在一周内完成，例如公开一篇短文、提出一次建议、穿一件真正喜欢的衣服。

## 50—60分钟｜整合

- 我是否用贬低对方来逃避自己的渴望？
- 哪种能力让我既向往又羞耻？
- 24小时内能启动哪个最小版本？
