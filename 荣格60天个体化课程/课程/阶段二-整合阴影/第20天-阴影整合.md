# 第20天｜阴影整合

> [!summary] 今日目标
> 把一个阴影内容转化为持续、可观察且符合伦理的能力练习。

## 0—10分钟｜安定

浏览第11—19天笔记，留意反复出现的一个词、人物或冲突。选择最有现实意义但可以承受的一项。

## 10—25分钟｜核心观念

阴影整合不会让阴影消失。它意味着意识能更早识别其出现，承认它携带的能量，并选择适合情境的表达。嫉妒可能转化为目标信息，攻击性转化为边界，虚荣转化为被看见的合理需要，控制欲转化为规划能力。

转化不是美化。若行为伤害了别人，责任仍需承担。真正整合总会产生现实变化，而不只是更漂亮的解释。

|---|---|---|---|---|
|  |  |  |  |  |

至少填写3项，从中选择一项作为未来7天实验。随后在 [[02-进度与测评]] 完成第20天评分与复盘。

## 50—60分钟｜整合

- 我承认了哪一个过去最不愿承认的部分？
- 我是否把“理解原因”误当成“免除责任”？
- 一周后用什么行为证据判断整合是否发生？
