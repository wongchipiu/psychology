# 第35天｜梦的补偿功能

> [!summary] 今日目标
> 检查梦是否对清醒时过度单一的态度提供了补充或纠偏。

## 0—10分钟｜安定

写下最近一周你最坚持的一句信念，例如“我必须保持理性”“我绝不能示弱”。

## 10—25分钟｜核心观念

[[梦与补偿]] 指梦可能对意识态度的片面性进行平衡。补偿不一定是相反意见，也可能是细化、质疑或展示被忽视的后果。

例如，白天把自己视为完全无助的人，梦中可能出现强壮动物；白天过度自信的人，梦中可能迷路。梦不是判决，而是邀请意识考虑更完整的信息。

## 25—50分钟｜练习：意识—梦对照

| 维度 | 清醒时的我 | 梦中的呈现 | 可能的补充 |
|---|---|---|---|
| 力量 |  |  |  |
| 关系 |  |  |  |
| 情绪 |  |  |  |
| 控制 |  |  |  |

写出三种补偿假设，再选一个安全的现实试验，例如表达一次脆弱或检查一个被忽略的细节。

## 50—60分钟｜整合

- 我白天最过度认同哪种态度？
- 梦提供的是反面、提醒还是校正？
- 如何实验而不把梦当成命令？
