# 第42天｜英雄原型

> [!summary] 今日目标
> 区分值得承担的挑战与为了证明自我而持续制造的战斗。

## 0—10分钟｜安定

回想最近一次你感觉“必须赢”的时刻，注意身体是否进入战斗姿态。

## 10—25分钟｜核心观念

英雄意象常代表离开熟悉秩序、面对危险、获得能力并返回共同体的发展过程。它可以带来勇气和纪律，但也可能让人沉迷于敌人、胜利和个人特殊性。

英雄阶段若不能结束，人会把休息看作软弱，把关系变成战场，把普通生活视为不够伟大。成熟英雄知道哪些战斗值得打，也知道胜利之后要返回、服务和接受限制。

## 25—50分钟｜练习：战斗审计

列出当前3场“战斗”：

| 战斗 | 真正价值 | 我想证明什么 | 成本 | 应继续/改变/退出 |
|---|---|---|---|---|
|  |  |  |  |  |

为值得继续的一项写出纪律行动；为应退出的一项写出停止信号。

## 50—60分钟｜整合

- 如果无需证明自己，我还会选择这场战斗吗？
- 谁在承担我的英雄剧情带来的代价？
- 我需要勇敢前进，还是勇敢结束？
