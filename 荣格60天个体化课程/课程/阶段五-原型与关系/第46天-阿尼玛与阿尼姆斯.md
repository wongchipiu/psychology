# 第46天｜阿尼玛与阿尼姆斯

> [!summary] 今日目标
> 用现代、非本质化的方式探索被人格排斥的“内在他者”。

## 0—10分钟｜安定

写下三组对立能力：果断/接纳、逻辑/感受、独立/连接。标记你更认同的一端。

## 10—25分钟｜核心观念

荣格用阿尼玛与阿尼姆斯描述心理中的性别化内在对立面。原始表述带有时代限制；本课程将 [[阿尼玛与阿尼姆斯]] 理解为被身份排斥、却有助完整性的内在他者，而不把能力固定给某一性别。

被排斥的一极常被投射到恋爱对象：对方似乎拥有自己缺少的一切。发展内在能力，可以减少关系承担“替我活出另一半人格”的压力。

## 25—50分钟｜练习：发展相反能力

选择3组对立面，填写：

| 我认同的一端 | 被排斥的一端 | 我对它的偏见 | 它的成熟版本 | 一周练习 |
|---|---|---|---|---|
|  |  |  |  |  |

练习必须具体，例如“听完再给方案”“明确提出一次请求”。

## 50—60分钟｜整合

- 哪种能力最容易被我性别化或贬低？
- 我把它投射到了谁身上？
- 如何在自己身上发展5%的版本？
