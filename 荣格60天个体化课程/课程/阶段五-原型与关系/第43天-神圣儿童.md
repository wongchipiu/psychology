# 第43天｜神圣儿童

> [!summary] 今日目标
> 找回好奇、游戏和新生能力，同时区分生命力与拒绝长大。

## 0—10分钟｜安定

回忆童年一个纯粹投入、忘记时间的活动。感受身体里是否仍有一点兴趣或温度。

## 10—25分钟｜核心观念

儿童原型既象征脆弱、新生、未来潜能，也具有依赖、全能幻想和逃避责任的一面。成人与“内在儿童”建立关系，不是让儿童掌管生活，而是由成年自我提供保护、边界和实现条件。

如果只强调受伤，容易永远停留在等待补偿；如果只强调责任，生命则可能变得干枯。两者需要合作。

## 25—50分钟｜练习：儿童需要，成人回应

写两栏对话：

| 儿童部分说 | 成年部分回应 |
|---|---|
| 我想玩/被看见/休息 | 我会在现实中安排___，但不会___ |
|  |  |

选择一个童年兴趣，设计本周20分钟、低成本、不为表现的恢复行动。

## 50—60分钟｜整合

- 我的儿童部分最缺什么？
- 我是否用童年受伤免除成年责任？
- 我能给生命力什么稳定容器？
