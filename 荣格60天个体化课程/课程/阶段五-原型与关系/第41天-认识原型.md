# 第41天｜认识原型

> [!summary] 今日目标
> 识别生活中反复出现的原型角色，并防止把自己等同于宏大角色。

## 0—10分钟｜安定

写下最近一周最常扮演的三个角色，例如拯救者、战士、受害者、照顾者或旁观者。

## 10—25分钟｜核心观念

[[原型]] 是荣格用来描述人类共有心理形式的概念。我们看见的不是原型本身，而是它在个人梦、神话、艺术和关系中的具体形象。原型被激活时，体验往往格外强烈、宏大和“命中注定”。

原型能提供方向，也可能造成膨胀。若一个人完全认同英雄、导师或救世主角色，就容易忽略普通限制和他人主体性。健康态度是与原型保持关系，而不是宣布“我就是它”。

## 25—50分钟｜练习：角色温度计

列出5个常见角色，分别评分0—10：

| 角色 | 出现情境 | 带来的力量 | 让我忽略的事实 | 强度 |
|---|---|---|---|---:|
|  |  |  |  |  |

圈出最强角色，写下：“当我进入这个角色时，别人被迫扮演什么？”

## 50—60分钟｜整合

- 哪个角色最容易让我感觉特殊或绝对正确？
- 它帮助我承担什么，又让我逃避什么？
- 如何把它缩小成一个有限的现实行动？
