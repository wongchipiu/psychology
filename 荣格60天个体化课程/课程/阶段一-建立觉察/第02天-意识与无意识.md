# 第02天｜意识与无意识

> [!summary] 今日目标
> 通过具体事件识别“我以为的理由”与实际自动反应之间的差距。

## 0—10分钟｜安定

观察周围5种颜色、4种触感、3种声音。写下此刻情绪和身体感受，提醒自己：今天只做观察，不急着解释一切。

## 10—25分钟｜核心观念

意识是此刻能够被自我看见和反思的部分；无意识则包含被遗忘、排斥和尚未形成语言的心理内容。它不只通过梦表达，也通过语气、身体紧张、口误、关系选择和重复模式显现。

无意识不是比理性更高明的“内在神谕”。它可能带来新的信息，也可能保存旧恐惧和偏见。训练目标是让意识与无意识形成对话，同时保留现实检验。参见 [[意识与无意识]]。

## 25—50分钟｜练习：三个自动时刻

选取最近3个“反应快于思考”的事件，分别填写：

| 项目 | 事件一 | 事件二 | 事件三 |
|---|---|---|---|
| 可观察事实 |  |  |  |
| 即时想法 |  |  |  |
| 身体反应 |  |  |  |
| 情绪与强度 |  |  |  |
| 行动冲动 |  |  |  |
| 事后给出的理由 |  |  |  |

圈出三次事件中重复出现的词语或身体信号。

## 50—60分钟｜整合

- 什么信号最先出现？
- 我事后的解释是否掩盖了更早的恐惧或需要？
- 下次出现相同信号时，我要对自己说什么？
