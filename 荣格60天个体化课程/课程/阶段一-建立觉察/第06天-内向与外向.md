# 第06天｜内向与外向

> [!summary] 今日目标
> 用“心理能量流向”理解内外倾，而不是给自己贴社交标签。

## 0—10分钟｜安定

回顾今天的能量变化：什么时候精神上升，什么时候下降？把能量从0—10画成一条简单曲线。

## 10—25分钟｜核心观念

荣格所说的内倾与外倾，指意识更自然地以主体内部经验还是外部对象为参照。内倾者可能擅长社交，外倾者也可能害羞；关键不在行为表面，而在注意力和判断主要从哪里获得方向。

两种态度都需要。过度外倾可能失去内部尺度，过度内倾可能忽视外界反馈。成熟不是改变类型，而是能在需要时使用相反态度。参见 [[心理类型]]。

## 25—50分钟｜练习：能量审计

列出过去一周各5个场景：

| 场景 | 独处/互动 | 能量前后变化 | 我注意的是内部还是外部 |
|---|---|---|---|
|  |  |  |  |

最后制定一个平衡实验：偏内倾者主动获取一次外部反馈；偏外倾者独处20分钟后再做判断。

## 50—60分钟｜整合

- 我在哪种情境最容易失去自己的尺度？
- 我是否把类型偏好当成逃避成长的借口？
- 明天要尝试哪一次相反态度？
