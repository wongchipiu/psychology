# 第09天｜与情结去认同

> [!summary] 今日目标
> 在“压抑情结”和“被情结接管”之间建立第三种位置：看见它，但暂不服从。

## 0—10分钟｜安定

说出你的姓名、日期、所在地点和今天的主要任务。感受双脚，提醒自己此刻处于成年人的现实环境。

## 10—25分钟｜核心观念

去认同化不是否认感受，而是改变语言和位置。“我很失败”把整个自我等同于一个判断；“失败情结被激活，我现在感到羞耻”则承认体验，同时保留观察者和选择空间。

成熟自我能够对情结说：“我听见你了，但今天的决定由我在获取事实后做。”这不是消灭无意识，而是建立关系。

## 25—50分钟｜练习：改写语言并排演

把最近常见的5句话改写：

| 融合语言 | 去认同化语言 |
|---|---|
| 我没人要 | 被抛弃警报被激活了，我现在害怕失去关系 |
|  |  |

然后站起来，用平稳声音演练3轮：

> “我注意到___情结被激活。我的身体正在___。我现在不做重大决定，先确认事实，___分钟后再回应。”

## 50—60分钟｜整合

- 哪种改写最能恢复选择感？
- 哪种说法容易变成逃避责任？
- 我准备把暂停脚本放在哪里？
