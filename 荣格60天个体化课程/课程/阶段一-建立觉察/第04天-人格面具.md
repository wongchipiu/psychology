# 第04天｜人格面具

> [!summary] 今日目标
> 识别不同社会角色中的自我呈现，以及每个面具的功能。

## 0—10分钟｜安定

写下今天你已经扮演过的角色，例如子女、同事、管理者、朋友。每写一个角色，感受身体姿态是否发生变化。

## 10—25分钟｜核心观念

[[人格面具]] 是我们与社会接触的界面。它让人能够专业、礼貌、可靠，也让不同关系拥有合适边界。问题不在于“戴面具”，而在于忘记面具只是局部角色。

过度认同面具时，人会把职位、能力、懂事或坚强当成全部身份；任何不符合形象的情绪都被推入 [[阴影]]。健康状态是既能履行角色，也知道角色之外仍有更完整的自己。

## 25—50分钟｜练习：角色地图

绘制下表，至少填写5个角色：

| 角色 | 我表现成什么样 | 它保护或带来什么 | 被隐藏的部分 |
|---|---|---|---|
|  |  |  |  |

然后标出：最自然的角色、最耗能的角色、最害怕失去的角色。

## 50—60分钟｜整合

- 哪个角色最接近“只能成功、不能失败”？
- 我隐藏的部分是否真的不适合出现，还是只是害怕评价？
- 今天可以进行什么安全的小幅真实表达？
