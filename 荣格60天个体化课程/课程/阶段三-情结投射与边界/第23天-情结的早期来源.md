# 第23天｜情结的早期来源

> [!summary] 今日目标
> 寻找当前反应与早期经验的相似性，同时避免把记忆当作完整事实。

## 0—10分钟｜安定

确认状态稳定，并阅读 [[03-安全边界]]。只选择普通、可承受的早期记忆；不主动挖掘严重创伤。

## 10—25分钟｜核心观念

情结通常围绕重复或高情绪事件形成，但记忆并非录像。今天寻找的是主观模式：“现在的什么感觉很熟悉？”而不是证明某个唯一历史原因。

理解来源可以带来同情，却不能让过去替现在做决定。成年后的现实资源、权力和选择往往已经不同，这种差异正是改变的基础。

## 25—50分钟｜练习：当时与现在

选择一个当前触发主题，填写：

| 维度 | 当时 | 现在 |
|---|---|---|
| 我的年龄与能力 |  |  |
| 对方拥有的权力 |  |  |
| 我可获得的支持 |  |  |
| 我能否离开或拒绝 |  |  |
| 最坏后果 |  |  |

最后写给当时的自己三句话，再写成年人现在能做的三件事。

## 50—60分钟｜整合

- 哪一种过去感正在覆盖现在？
- 现在最重要的新资源是什么？
- 我如何在不责怪过去自己的前提下改变策略？
