# 第28天｜建立心理边界

> [!summary] 今日目标
> 区分自己的责任、对方的责任和共同协商范围。

## 0—10分钟｜安定

在纸上画两个相交的圆，分别写“我”和“对方”。感受“分开但能连接”这一图像。

## 10—25分钟｜核心观念

边界不是让别人按照你的愿望行动，而是说明当某种情况发生时，你会如何保护自己的时间、身体、资源和价值。边界的执行部分必须掌握在自己手里。

投射和情结会让边界失真：讨好者把一切当成自己的责任，控制者把对方的选择也当成自己的责任。成熟关系需要分化，而不是冷漠或融合。

## 25—50分钟｜练习：责任三分法

选择一段现实关系，填写：

| 我的责任 | 对方的责任 | 共同协商 |
|---|---|---|
| 表达需要、执行后果 | 对方的感受和选择 | 时间、分工、共同规则 |
|  |  |  |

写一条边界：“当___发生时，我会___；如果持续，我将___。”检查后果是否具体、合法、可执行。

## 50—60分钟｜整合

- 我是否在管理对方的情绪？
- 我是否期待对方替我读心？
- 哪条边界应先从小场景练习？
